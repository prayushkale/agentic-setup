## Three.js browser games
- Start game work with the `threejs-game-director` skill; it routes to the other `threejs-*` skills. Check Three.js APIs against the current docs (Context7) rather than memory, since the API changes between releases.
- Inspect the running scene with the threejs-devtools MCP instead of guessing from the code.
- Generate 3D models, images and audio through the fal MCP, then clean up and rig models in Blender through the blender MCP.
- Do not add paid or hosted asset services or API keys beyond these without asking the user first.
