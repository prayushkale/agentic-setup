# Superpowers (skills for other agents)

The same Superpowers skills for agents without Claude Code's plugin system, installed as plain skills. Claude Code gets the plugin instead.

| Field | Value |
| --- | --- |
| Pack | core |
| Kinds | skill |
| Agents | command-code, codex, gemini-cli, generic |
| Benefit | quality |
| Source | npx-skills: obra/superpowers |
| Redistribution | upstream-public |
| Risk | low |
| Startup tokens | about 814 |
| Requires | none |
| Conflicts | none |

## What the installer does

- Skills from `obra/superpowers`: brainstorming, diagnosing-superpowers, dispatching-parallel-agents, executing-plans, finishing-a-development-branch, receiving-code-review, requesting-code-review, subagent-driven-development, systematic-debugging, test-driven-development, using-git-worktrees, using-superpowers, verification-before-completion, writing-plans, writing-skills.

Install it with `npx agentic-setup install superpowers-skills`.
