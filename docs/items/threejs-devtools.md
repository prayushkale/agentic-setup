# threejs-devtools MCP

Lets the agent inspect and tweak a live Three.js scene in the browser, including objects, materials, shadows, performance and screenshots, instead of guessing from the code.

| Field | Value |
| --- | --- |
| Pack | threejs |
| Kinds | mcp |
| Agents | claude-code, command-code, codex, gemini-cli |

| Redistribution | upstream-public |
| Risk | low |
| Startup tokens | about 300 |
| Requires | node>=20 |
| Conflicts | none |

## What the installer does

- MCP server `threejs-devtools` (stdio).

Install it with `npx agentic-setup install threejs-devtools`.
