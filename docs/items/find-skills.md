# find-skills

Lets the agent search for an existing skill when you ask "is there a skill for this?", instead of building one from scratch.

| Field | Value |
| --- | --- |
| Pack | core |
| Kinds | skill |
| Agents | claude-code, command-code, codex, gemini-cli, generic |
| Benefit | speed |
| Source | npx-skills: vercel-labs/skills |
| Redistribution | upstream-public |
| Risk | low |
| Startup tokens | about 89 |
| Requires | none |
| Conflicts | none |

## What the installer does

- Skills from `vercel-labs/skills`: find-skills.

Install it with `npx agentic-setup install find-skills`.
