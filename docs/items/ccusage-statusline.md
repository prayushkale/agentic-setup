# ccusage status line

Shows the session's cost, today's spend, the 5-hour usage block and context use in Claude Code's status line.

| Field | Value |
| --- | --- |
| Pack | core |
| Kinds | cli-tool, settings |
| Agents | claude-code |
| Benefit | cost |
| Source | npm: ccusage |
| Redistribution | upstream-public |
| Risk | low |
| Startup tokens | about 0 |
| Requires | none |
| Conflicts | none |

## What the installer does

- Keys merged into the agent settings file.
- Runs: `npm i -g ccusage`.

## Uninstall

- `npm uninstall -g ccusage`

Install it with `npx agentic-setup install ccusage-statusline`.
